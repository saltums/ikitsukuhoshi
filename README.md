# いきつくほし

行き着く星か、生き尽くす星か。

ビッグバンから文明の終わりまで、ひとつの星の一生を見届けるブラウザゲームです。応援する星を選び、命が生まれ、進化し、文明が栄えて終わっていく様子を眺めます。ときどき「神の一手」を使うかどうか聞かれます。

- 遊ぶ: GitHub Pages で公開(`index.html` 1ファイルで動きます)
- 同じ銀河コードなら、いつでも同じ歴史になります

## 続編「いきつくもの」

行き着く者か、生き尽くす者か。

`mono/` にある続編です。前作の結果画面の銀河コードから、その星の「その後」を計算し直し、生き残った種族の一人とその一族の三代を見守ります。前作の結果画面の「続編『いきつくもの』でこの続きを見る」からも開けます。

- 前作の計算は `engine/sim-v1.js` をそのまま使うので、前作と同じ星・同じ種族・同じ「ことば」や「文化」から始まります
- 結末は8種類(王になる・文明を再起動・途絶える・概念になる・罪人になる・旅立ち・溶け込む・静かな暮らし)と、めったに出ない異色エンドが56種類
- 共有リンク `mono/?c=銀河コード&k=人物&h=神の一手` で、同じ物語を再現できます
