# シミュレーションエンジン(結果の再現用)

`sim-v1.js` は「いきつくほし」版1(SIM_VER=1)の計算部分を、そのまま凍結したものです。
共有リンクや引き継ぎコードの結果は、このファイルで計算し直すと同じになります。

## 版の決まり

- 確率・出来事・名前の作り方など、結果が変わる変更をしたら `SIM_VER` を上げる
- 上げる前の版は `sim-v{番号}.js` としてここに残し、消さない
- 共有リンクの `ver=`、引き継ぎコードの `IKH{番号}-` が、どの版で作られたかを表す

## 銀河コードの形

結果画面に出る銀河コードは、その結果をまるごと再現できるコードです。

```
TRX01-R2-O1-MD1R0-W2X1-V1
```

`-` で区切った各部分の意味です。先頭以外は、あるものだけが付きます。

| 部分 | 意味 |
|---|---|
| TRX01 | 銀河(先頭。これだけのコードは、その銀河を最初から遊ぶ) |
| R2 | 宇宙のにぎやかさ(0=リアル、1=ふつう、2=にぎやか) |
| O1 | 推しの星の番号(0から) |
| MD1R0 | 使った神の一手(種類の1文字+星の番号の並び。S=生命の種、A=水の彗星、D=軌道をそらす、I=小惑星を落とす、M=衛星、R=資源小惑星) |
| W2X1 | 別の世界線に切り替えた星(星の番号X世界線、複数は . でつなぐ) |
| V1 | 計算の版(これが付いているコードは、結果画面をそのまま開く) |

## 再現のしかた

```js
RARE = 2;                                       // R
const gal = simulate('TRX01', {2: 1},           // 銀河, W
  [{k: 'deflect', p: 1}, {k: 'res', p: 0}]);    // M
const oshi = gal.planets[1];                    // O。oshi.events / oshi.lineage に歴史のすべてが入っている
```
