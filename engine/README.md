# シミュレーションエンジン(結果の再現用)

`sim-v1.js` は「いきつくほし」版1(SIM_VER=1)の計算部分を、そのまま凍結したものです。
共有リンクや引き継ぎコードの結果は、このファイルで計算し直すと同じになります。

## 版の決まり

- 確率・出来事・名前の作り方など、結果が変わる変更をしたら `SIM_VER` を上げる
- 上げる前の版は `sim-v{番号}.js` としてここに残し、消さない
- 共有リンクの `ver=`、引き継ぎコードの `IKH{番号}-` が、どの版で作られたかを表す

## 引き継ぎコードの形

`IKH1-` のあとに、次の JSON を base64url にしたものが続きます。

```json
{"ver":1,"g":"銀河コード","r":1,"o":2,"m":[["deflect",1],["res",0]],"w":{"2":1}}
```

| キー | 意味 |
|---|---|
| ver | シミュレーションの版 |
| g | 銀河コード |
| r | 宇宙のにぎやかさ(0=リアル、1=ふつう、2=にぎやか) |
| o | 推しの星の番号(0から。なければ省略) |
| m | 使った神の一手([種類, 星の番号] の並び。なければ省略) |
| w | 別の世界線に切り替えた星({星の番号: 世界線}。なければ省略) |

## 再現のしかた

```js
RARE = d.r;
const gal = simulate(d.g, d.w || {}, (d.m || []).map(([k, p]) => ({ k, p })));
const oshi = d.o != null ? gal.planets[d.o] : null;   // oshi.events / oshi.lineage に歴史のすべてが入っている
```
